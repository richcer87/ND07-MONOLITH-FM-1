1

Conecta el FM-1

Cable USB de datos, el FM-1 encendido. Cierra REAPER y cualquier programa que use su MIDI.

2

Elige el firmware

Última compilación

La que GitHub compiló del último cambio en main.

Arrastra aquí un archivo .fwsc (o haz clic para elegirlo)
3

Instala

Tarda alrededor de un minuto. No desconectes el FM-1 mientras escribe; se reinicia solo al terminar.

Detalles


  

    Si algo se corta: vuelve a conectar y presiona Instalar otra vez; el FM-1 sigue en modo de actualización
    hasta que termine. Si no arranca: mantén OCT− al encenderlo (rescate USB). Para volver al firmware
    oficial: The FM-1 Firmware Hub.
    
Protocolo de actualización: fm1ota.js y fm1pkg.js de SLOOP
